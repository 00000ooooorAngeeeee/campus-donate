# 拾光 · 校园旧物捐赠平台

> 面向本校毕业季的闲置物品捐赠与领取平台，让每一件物品的流转都有据可查。

《Web前端开发技术与UI设计》期末大作业 · 第三小组

---

## 项目定位

毕业季产生大量仍可使用的教材、衣物、小家电，通常直接进垃圾桶或楼道杂物堆；同时在校低年级学生存在真实需求，但两侧无法对接。问题不在"没有物品"，而在**没有可信的中间环节**：信息散落在群聊里、线下捐赠没有台账、物品混堆无分类、捐赠者不知道东西最终去了哪。

本项目建立校内闭环：捐赠登记 → 管理员审核 → 送达驿站收货入库 → 领取者浏览预约 → 凭码核销 → 流转履历可查。

**差异化设计**：每件物品有一条完整的流转履历时间轴，并折算 CO₂e 减排量。前者解决公益透明度，后者把环保价值量化。

## 产品原型

入口：[原型/00-原型总览.html](原型/00-原型总览.html)（双击即可在浏览器打开，无需服务器）

| 页 | 内容 |

| 02 发现 | 运营位、四维筛选、余量实时、骨架屏 |
| 03 物品详情与预约 | 余量进度、驿站信息、流转履历时间轴 |
| 04 捐赠登记 | 6 个必填项、图片前端压缩、驳回后重提 |

## 技术选型

| 层 | 选型 |
| --- | --- |
| 前端 | Vue 3.4 + TypeScript(strict) + Vite 5 + Vue Router 4 + Pinia + axios + zod |
| UI | 用户端手写 CSS + 设计 token；后台 Element Plus |
| 图表 | ECharts 5 |
| 后端 | Node 20 + Express 4 + Prisma 6 + SQLite（**薄后端**：≤20 接口，不做分层） |
| 认证 | JWT 单 token + bcryptjs |
| 包管理 | npm |

**两个刻意的取舍**：余量不落库（只存 `totalQty / reservedQty / collectedQty`，可用量查询时派生）；并发占用用条件 `UPDATE` 而非先查再改。
